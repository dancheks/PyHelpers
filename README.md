# `fsearch` — консольная утилита для поиска текста в файлах

Быстрый рекурсивный поиск подстрок внутри текстовых файлов с выводом точного пути к файлу и номера строки. Работает на стандартной библиотеке Python без сторонних зависимостей.

## Возможности

* **Рекурсивный поиск:** сканирует указанную папку и все вложенные в неё поддиректории.
* **Точный вывод результатов:** показывает полный путь к файлу, номер строки и само содержимое найденной строки, а в конце выводит общее количество совпадений.
* **Фильтрация по расширениям (`-e`):** позволяет ограничить поиск конкретными форматами файлов (работает как с точкой `.txt`, так и без неё `txt`, регистр расширения не важен).
* **Регистронезависимый поиск (`-i`):** умеет искать текст без учёта заглавных и строчных букв.
* **Умный пропуск системных папок и мусора:**
  * автоматически игнорирует служебные директории (`AppData`, `Application Data`, `Local Settings`, `$RECYCLE.BIN`, `.git`);
  * пропускает бинарные/не-UTF-8 файлы и файлы без прав доступа без падения скрипта;
  * исключает из поиска сам файл скрипта.
* **Безопасная остановка:** корректно завершает работу по нажатию `Ctrl+C` без вывода системных ошибок.

## Установка (Windows)

Выполните в PowerShell (скрипт сам проверит наличие Python, установит пакет в профиль пользователя и пропишет команду в `PATH`):

```powershell
irm https://githubusercontent.com | iex
```
*(После установки перезапустите окно терминала).*

## Использование и параметры

```bash
fsearch <текст> [-d <путь>] [-e <расширения...>] [-i]
```

| Аргумент / Флаг | Описание | По умолчанию |
| :--- | :--- | :--- |
| `text` | Обязательный. Текст или подстрока для поиска. | — |
| `-d`, `--dir` | Директория, в которой нужно искать файлы. | `.` (текущая папка) |
| `-e`, `--ext` | Список расширений через пробел (например: `py txt` или `.log .md`). | Все текстовые файлы |
| `-i`, `--ignore-case` | Игнорировать регистр букв при поиске. | Выключено (точный регистр) |

### Примеры команд

* **Поиск в текущей папке (с учётом регистра):**
  ```bash
  fsearch "TODO"
  ```
* **Поиск в конкретной директории без учёта регистра:**
  ```bash
  fsearch "A1" -d "D:\Work" -i
  ```
* **Поиск только среди `.py` и `.txt` файлов:**
  ```bash
  fsearch "import os" -d "C:\Projects" -e py txt
  ```
